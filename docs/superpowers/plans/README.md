# Plans

Historical records of past implementation work. Each document captured a plan as it stood when it was written; the code has since moved on. Some plans describe machinery that no longer exists — nothing in this directory describes the current system, and no plan here is kept up to date.

Do not design or build against these documents.

The current sources of truth for design and vocabulary:

- [CONTEXT.md](../../../CONTEXT.md) — the domain glossary: the terms the code and docs use, and the terms they deliberately avoid.
- [docs/adr/](../../adr/) — architecture decision records: the decisions that still stand and the reasoning behind them.

The plans remain in the repo, unedited, so the reasoning behind past work stays traceable.
